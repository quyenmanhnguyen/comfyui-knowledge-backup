# ComfyUI knowledge backup

This repository stores the lightweight working memory for the local ComfyUI setup on `C:\AI`.

It intentionally includes:

- Codex ComfyUI optimization skill and references
- Machine/runtime notes
- Visual gate / blacklist rules
- Telegram/Civitai learning summaries
- Small workflow reports and contact sheets

It intentionally excludes:

- Telegram tokens, sessions, API credentials, and secrets
- Models, checkpoints, LoRAs, VAEs, `.safetensors`, `.ckpt`, `.gguf`
- Full ComfyUI output folders
- Python embedded runtime and installed packages

Use this repo as the recovery source if the local Codex skill/evidence gets lost.
